# 严格仿真实验流程

## 1. 仿真要回答的问题

本代码库不是用一次“看起来有效”的曲线证明工程可行，而是依次检验五个可证伪问题：

1. 多源设备状态是否能在未见工况上预测铯光泵位置的三轴自磁场及局部梯度？
2. 独立线圈通道的场—梯度响应是否能由台架数据识别，并外推到多通道同时工作？
3. 阵列拆除、模型固化且存在源漂移和线圈漂移后，前馈仍能否显著降低探头处残余自磁场？
4. 高机动期间全梯度张量最大主值超过 G-882 容限时，完整五自由度梯度通道能否把它恢复到合规区间？
5. 外部磁目标完全不进入控制器时，其波形在补偿后是否仍被铯光泵保留？

当前版本的结论层级仅为“模型在环筛选”。它不能替代有限元、线圈热设计、电磁兼容测试、台架实测和海试。

## 2. 因果链与信息边界

```text
设备状态/温度 ──> 多偶极子真实正演 ──> 台架多点矢量阵列
       │                                      │
       └──────────────────────────────> 源模型标定

已知线圈电流/温度 ──> 真实线圈模型 ──> 台架多点矢量阵列 ──> 线圈响应模型

航前独立锚点 ──> 源/线圈迁移参数 ──┐
航行设备状态/温度 ──> 已固化源模型 ──> 前馈电流命令 ──> 因果预加重/驱动动态/真实线圈
外部目标 + 地磁场 + 残余自磁场 ────────────────────────> 铯光泵标量读数
```

硬约束：航行阶段不安装高精度阵列；源模型和线圈模型均不在线更新；铯光泵输出不进入控制器；外部目标不参与线圈命令计算。这些边界可从返回结果中的 `manifest` 审计。

## 3. 台架数据集设计

源模型采用场景级隔离，不能随机打散相邻时间点：

| 数据角色 | 场景 | 允许用途 |
|---|---|---|
| 基础训练 | 4个单源、4个双源、随机多频、温度扫描、随机瞬态及2组高动态激励，共13组 | 拟合基础源模型 |
| 有限残差修正 | 常规混合激励、高动态混合激励，共2组 | 仅拟合残差，修正幅度受上限约束 |
| 完全留出验证 | DC/DC—作动器组合、四源联合组合、高机动联合组合，共3组 | 只报告泛化误差，禁止调参回看 |
| 航前迁移训练 | 两组独立锚点激励 | 仅识别当前艇体相对基线的传递变化，不重训基础模型 |
| 航前迁移留出 | 一组不同频率、时序的混合锚点 | 只验证迁移量；禁止进入迁移拟合 |

线圈模型使用8个单通道扫频/阶跃作训练，8通道同时随机平滑激励作完全留出验证。航前再使用一套新单通道激励辨识当前线圈传递矩阵，并用新的多通道同时激励留出验证。源迁移采用“当前锚点观测减基线锚点观测”的差分标签，减少把基础模型误差错误吸收到漂移修正中的风险。

多点阵列使用中心参考点和`±X/±Y/±Z`六个测点组成的7点对称构型，默认半基线10 mm。中心点给出保护位置的三轴场，成对轴向测点通过中心差分得到梯度，再施加无源区梯度张量对称且迹为零的约束。实际台架仍需验证阵列位置误差、轴不正交、时间同步和探头标定误差。

## 4. 航行对照实验

每次运行生成同一轨迹、同一设备工况、同一外部目标及同一铯光泵噪声，实现四组配对对照：

- `none`：线圈命令为零；
- `uniform`：仅三轴均匀场线圈前馈；
- `joint_main`：三轴均匀场线圈 + 单个主梯度 `Gxx` 通道，用于复现原简化方案的边界；
- `joint`：三轴均匀场线圈 + 五个独立梯度通道联合前馈。

界面提供四档：理论上限、温和工程误差、较强扰动和高机动越限验证。默认使用高机动档：20 A推进器参考电流、35 A等效峰值、约0.1 s级快速边沿和15倍初步等效磁矩压力，使无补偿最大主梯度明确超过10000 nT/m；同时加入阵列误差、传感器噪声、航前0.5%源/线圈偏移、航前固化后0.03%源/线圈短时剩余漂移、8 A电流限制、250 A/s压摆率、0.015 s真实驱动时间常数和5%时间常数辨识误差。驱动预加重是辨识一阶环节的因果逆，仅使用当前及上一拍前馈需求。15倍磁矩与线圈能力倍率均为压力试验参数，不是实艇标定值。

梯度容限判定不只检查`Gxx`，而是从5个独立分量重建对称无散梯度张量，取最大绝对特征值。报告656 nT/m预警、10000 nT/m额定容限、越限时长、越限事件和合规读数占比。

铯光泵输出由总矢量磁场取模，再通过有限带宽、白噪声和随机游走得到。界面为了看清纳特斯拉级变化，显示“实际标量读数减去地磁模长”；保存 CSV 时同时保留绝对读数。

## 5. 指标和预注册筛选线

理论上限阶段的筛选线在查看正式10随机种子结果前固定为：

- 航行三轴源预测RMSE最差值不超过0.1 nT；
- 航行`Gxx`预测RMSE最差值不超过0.25 nT/m；
- 联合补偿后三轴残余场RMS最差值不超过0.1 nT；
- 联合补偿后`Gxx`残差RMS最差值不超过0.25 nT/m；
- 外部目标配对反事实波形相关系数不低于0.999999。

这些阈值只是当前概念阶段的仿真筛选线，不是产品验收指标。实物研制前必须根据铯光泵动态范围、允许残差、目标信号量级、线圈温升与供电预算重新冻结。

高机动工程档另外预注册：联合补偿三轴残余场 RMS 和铯光泵综合误差 RMS 在每个随机种子中均小于 1 nT；无补偿最大主梯度必须大于 10000 nT/m；联合补偿最大主梯度必须小于 656 nT/m，且不得发生额定梯度越限或电流饱和。

## 6. 稳健性与消融矩阵

正式报告不应只使用默认随机种子。本轮模型升级验证运行：

```powershell
python validate_upgrade.py --seeds 10
```

该命令形成旧模型10例、新模型10例及2/4/8%源漂移压力测试30例，共50例，并保存逐案例CSV、汇总JSON、均值、95%分位数和最差值。

四档界面参数使用以下命令单独验证：

```powershell
python validate_presets.py --seeds 10
```

该命令对理论上限、温和工程误差、较强扰动和高机动越限验证各运行10个随机种子，共40例；高机动档额外检查无补偿必然越限、联合补偿后峰值低于656 nT/m、越限时长为0，以及训练幅值/变化率包络覆盖航行输入。

`python validate_field_goal.py --seeds 10` 单独复核 1 nT 目标，并在同一随机种子下比较旧路径、仅航前迁移、仅预加重和两者联合，防止仅凭最终曲线归因。

建议另外固定同一批种子完成下列消融：关闭有限残差修正；将梯度权重设为0；逐个移除五个梯度通道；改变阵列噪声；将目标关闭以检查控制命令是否完全不变；扫描电流限幅和驱动时间常数。

## 7. 从仿真到实物的替换顺序

1. 用真实线圈三轴场/多点梯度扫描替换 `CoilSystem`，先不改控制器接口。
2. 用各设备单源和组合台架采集替换 `MagneticSourceSystem`，保留场景级数据隔离。
3. 加入阵列安装坐标误差、传感器轴误差、时间戳误差、磁滞和结构硬磁/软磁项。
4. 在线圈热设计和驱动器台架验证后冻结电流、压摆率、温升和功耗约束。
5. 先做磁静态环境中的系留试验，再做无目标航行，最后做带已知磁目标的盲测航线。

每一步都应保存原始数据、校准参数、代码版本、配置文件和随机种子，避免用同一航次既调参又宣称验证。
